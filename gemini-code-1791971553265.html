Level-Up Summary

📊 FCE Essay (5 Paragraphs) vs. IELTS Writing Task 2 (4 Paragraphs)

Feature B2 First (FCE) Opinion Essay 🌟 IELTS Writing Task 2 (Secret Boss)
1. Word Count 140 – 190 words (Concise & compact) At least 250 words (In-depth & fully developed)
2. Prompts & Ideas Guided Safety Net: 2 given notes + 1 "your own idea" 100% Independent: 0 notes given — you brainstorm all main ideas!
3. Essay Structure
5 Paragraphs:
• Para 1: Introduction • Para 4: Short Body 3 (Note 3) • Para 2: Short Body 1 (Note 1) • Para 5: Conclusion • Para 3: Short Body 2 (Note 2)
4 Paragraphs:
• Para 1: Introduction • Para 2: Deeply Developed Body 1 (View A + Explanation + Example) • Para 3: Deeply Developed Body 2 (View B + Explanation + Example) • Para 4: Conclusion
4. Paragraph Depth ~35 – 45 words per body paragraph (Main point + brief reason) ~90 – 100+ words per body paragraph (Topic Sentence ➔ Explanation ➔ Example ➔ Result)
💡 Key Takeaway: You keep 100% of your linking words from FCE! To level up to IELTS Task 2, we trade 3 short body paragraphs for 2 deeply explained body paragraphs backed by real-world examples.
